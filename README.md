# Blazor Basic Component Logo Sample

Ejemplo práctico y sencillo de desarrollo de un **componente básico en Blazor (C#)** que implementa y muestra un logotipo de manera reutilizable. Este proyecto sirve como plantilla o guía introductoria para comprender la creación de componentes personalizados en aplicaciones Blazor (tanto Server como WebAssembly).

A través de un ejemplo paso a paso, exploramos dos de los conceptos más importantes y potentes del desarrollo con Blazor: 
🔹 Encapsulamiento: Cómo centralizar la estructura y lógica visual en un solo lugar. 
🔹 Reutilización de código: Cómo insertar y modificar componentes fácilmente en múltiples vistas sin duplicar código.
